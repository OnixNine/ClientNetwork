# protocol

Пакеты, кодеки и шифрование IRC-чата (`ru.kseonyt.net.*` + `me.onixdev.ircchat.impl.*`).
Netty внутри перепакован в `dev.test.netty`, поэтому модуль не конфликтует
с netty из Minecraft.

## Лицензия

Этот модуль распространяется под **MIT** (см. [`LICENSE`](LICENSE)) — в отличие
от сервера и мода, которые под GNU GPL-3.0. Это сделано намеренно: `:protocol`
можно встраивать в сторонние проекты, в том числе с закрытым исходным кодом.

MIT распространяется только на содержимое каталога `protocol/`. Код сервера
(корневой модуль) и Fabric-мода (`:fabric`) остаётся под GPL-3.0.
